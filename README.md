# Be the Bee 🐝

**▶ 지금 플레이: https://soomin007.github.io/be-the-bee/**

> 같은 색 꿀벌 5마리를 한 줄로 연결해 **벌집의 주인**이 되세요.

2인용 육각(hex) 그리드 추상 전략 보드게임 "Be the Bee"의 웹 디지털 구현입니다.
종이 보드게임을 그대로 옮기되, 핵심은 나중에 네이티브(예: Capacitor)로 감싸도
다시 짜지 않아도 되는 **이식 가능한 순수 규칙 엔진**입니다.

원작 보드게임: 김수민 · 김재현 · 조주현 / 프로그램 구현: 김수민

---

## 어떤 게임인가

육각형 칸이 곧 **벌집(honeycomb)** 입니다. 두 사람이 노랑 / 갈색 진영을 맡아
**타일**을 깔며 판을 키우고, 그 위에 **말(꿀벌)** 을 올립니다.

- **목표**: 내 말 **5개 이상을 한 줄로** 연결하면 즉시 승리(육각 3축 중 한 방향).
- **한 턴**: ① 타일 2개 놓기, 또는 ② 타일 1개 놓고 말 1개 올리기.
- **벌집(hive)**: 같은 색 타일이 5개 이상 한 줄로 이어지면 벌집이 되고,
  그 위에는 벌집 주인만 새 말을 올릴 수 있습니다(자리 다툼의 핵심).
- **승부가 안 나면**: 타일을 다 쓰면 벌집 점수(긴 벌집일수록 고득점)로 가립니다.

규칙 전문은 [`docs/design/rules.md`](docs/design/rules.md)가 단일 진실입니다(v0.4).

## 기능

**대전 방식**
- 👥 **한 기기에서 2인**(핫시트) · 🤖 **AI와 대결** · 👀 **AI끼리 관전**
- 🔗 **온라인 1:1 초대 대전** — 방을 만들어 링크/코드만 보내면 친구와 바로 대국.
  선공·후공 협상(원하면 코인토스), 이탈·재접속 복구, 한 판 더(재대국), 온라인 무르기까지.

**규칙 변형(설정 토글)**
- 👑 **여왕벌 모드** — 게임 중 단 한 번, 상대 벌집 위에도 놓을 수 있는 여왕벌.
- ♾️ **무한 모드** — 타일 개수 제한 없이 끝까지.

**초보를 위한 도움**
- 첫 접속 **앱 사용법 투어** + **게임 규칙 튜토리얼**(언제든 다시 보기).
- ⚠️ **위험 경고**(상대의 다음 한 수 5목·막을 수 없는 벌집 초읽기, 기본 켜짐)와
  💡 **승리 힌트**(내가 5목 낼 칸)를 따로 켜고 끌 수 있습니다.
- 전문가 AI와 둘 때 내 수를 짚어주는 **코칭** 멘트.

**편의 · 연출**
- 💾 저장 · 이어하기 · **복기(리플레이)** · 기보 코드로 공유/가져오기.
- 🎨 컬러 테마(꿀 / 고대비 / 벽돌) · **3D 보드** 옵션 · 모바일 전용 레이아웃.
- 꽃가루 반짝, 꿀이 차오르는 벌집 완성, 벌 날갯짓 효과음, 배경음악.

## 구조 (아키텍처)

엔진과 UI는 **서로 섞이지 않습니다.** 엔진은 이식 가능한 자산입니다.

| 경로            | 설명                                                                 |
| --------------- | -------------------------------------------------------------------- |
| `src/engine/`   | **순수 TypeScript** 규칙 엔진. DOM·브라우저 전역 없음. 결정적·단위 테스트 대상. |
| `src/ui/`       | SVG 렌더링 + 입력 처리. 엔진에 의존하지만 **엔진은 ui를 import하지 않음.** |
| `src/mp/`       | 온라인 대전(방·동기화) 얇은 층(Supabase). 게임 상태는 직렬화 스냅샷으로만 주고받음. |
| `tests/`        | Vitest 단위 테스트(엔진 규칙 + UI).                                  |
| `design/`       | `rules.md` — 게임 규칙 명세(구현 기준).                               |
| `docs/`         | 설계·운영 문서. 진입점은 [`docs/INDEX.md`](docs/INDEX.md).            |

좌표는 **큐브 좌표(q, r, s)** 를 쓰고, 보드는 동적으로 자라므로 고정 2D 배열이 아니라
좌표 키 희소 맵(`Record<string, Cell>`, JSON 직렬화 가능)으로 저장합니다.

## 기술 스택

Vite · TypeScript(strict) · Vitest · **SVG** 보드 렌더링 · three.js(3D 보드 옵션) ·
Supabase(온라인 대전). 상태 관리 라이브러리 없음 — 엔진 상태는 JSON 직렬화 가능한
순수 객체라 무르기·복기·저장·네트워크 동기화가 모두 같은 스냅샷 한 가지로 돌아갑니다.

## 명령어

| 명령                    | 설명                                                  |
| ----------------------- | ----------------------------------------------------- |
| `npm run dev`           | 로컬 개발 서버                                        |
| `npm test`              | 엔진 + UI 테스트 1회 실행(Vitest)                     |
| `npm run test:watch`    | 테스트 watch 모드                                     |
| `npm run typecheck`     | 전체 타입체크(`tsc --noEmit`)                         |
| `npm run check:engine`  | 엔진 순수성 검사(엔진이 DOM/Node API를 쓰면 실패)     |
| `npm run build`         | 타입체크 + 프로덕션 빌드(`dist/`)                     |
| `npm run preview`       | 빌드 결과 미리보기                                    |
| `npm run sim`           | AI 난이도·성향 상성 self-play 시뮬레이션(분석, 느림)  |
| `npm run verify:click`  | Playwright 보드 클릭 회귀 테스트                      |

온라인 대전을 로컬에서 켜려면 `.env.local`에 Supabase 키가 필요합니다(없어도 나머지
모드는 모두 동작). 배포는 GitHub Pages 자동(`.github/workflows/deploy.yml`).
