# 벌 컨셉 비주얼 테마 (제안)

> "Be the Bee"의 벌·꿀·벌집 컨셉을 디자인에 녹이는 방향. 아직 미구현 — 별도 세션에서
> 단계적으로 적용. 이 게임은 보드 자체가 **육각형 = 벌집(honeycomb)** 이라 테마가 자연스럽다.

## 왜 잘 맞나
- 육각 그리드 = 벌집 구조. 이미 "벌집(hive)" 규칙도 있음.
- 색(노랑/갈색) = 꿀/밀랍. 금색 벌집 글로우도 이미 꿀 느낌.

## 단계별 아이디어

### 1단계 — 팔레트 & 말 모양 ✅ (부분 적용, 2026-06-21)
- ✅ **팔레트**: 따뜻한 꿀색 그라데이션 배경.
- ✅ **말 = 벌**: 흰 날개 2개 + 진영색 몸통 + 줄무늬. 진영은 몸통 색으로 구분.
- ✅ **여왕벌**: 줄무늬 위 ♛.
- ⬜ **타일**: 밀랍 셀 질감(미묘한 육각 안쪽 음영) — 미적용. 다음에.
- ⬜ 벌을 더 디테일하게(꿀방울 대안 등) — 취향 따라.

### 2단계 — 연출 & 사운드
- **놓기**: 살짝 윙~ 하는 벌 날갯짓 소리(현재 합성음에 가미) + 착지 시 꽃가루 반짝.
- **벌집 완성**: 금색 꿀이 차오르는 글로우/물결.
- **승리**: 벌 떼가 5목 라인을 따라 날아가거나 꿀이 튀는 연출 + 결과 모달에 벌 마스코트.
- **리치 경고**: 벌이 붕붕대는 경고 모션.

### 3단계 — 아이덴티티
- **로고/마스코트**: 친근한 벌 캐릭터(타이틀/탭 아이콘/모달).
- **배경**: 아주 옅은 벌집 패턴(현재 점선 그리드를 벌집 무늬로).
- **커서/버튼**: 꿀색 톤 통일(일부 적용됨).

## 제약 / 원칙
- 가독성 우선: 벌 모양이 5목 라인·진영 구분을 흐리면 안 됨. 색 대비 유지.
- 가볍게: 외부 이미지 의존 최소화, SVG/CSS·합성음 위주(에셋 추가는 BGM 정도).
- 단계적으로: 1단계(팔레트+말 모양)만 해도 분위기가 확 산다 — 거기서 시작.
