# 설정 패널 비주얼 핸드오프 (Claude Design 용 맥락 문서)

이 문서는 **Be the Bee**의 왼쪽 설정 패널을 더 "디자인된" 느낌으로 다듬기 위해
Claude Design 에 그대로 붙여넣어 쓰는 맥락 자료다. 결과물(아이콘 SVG, 컨트롤 스타일 CSS)을
받아 코드에 끼워 넣으면 된다.

## 1. 앱 한 줄 소개
2인용 육각 보드게임 "Be the Bee"의 웹 버전. 꿀벌·벌집·꿀 테마(따뜻한 호박/꿀빛). 보드는 SVG,
설정 패널은 좌측 고정 사이드바(폭 320px).

## 2. 테마 색 토큰 (현재 코드 기준, 이걸 그대로 따라줘)
- 배경/카드: `#fffdf7`(가장 밝음) · `#fbf3df` · `#f1e4c5`(연한 꿀)
- 테두리: `#e6dcc3` · `#d9c89a` · `#c9b88f`
- 글자: `#2b2b2b`(본문) · `#6b5524`(라벨) · `#5a3a14`(강조)
- 꿀빛 골드(아이콘/포인트): `#c2982f` · `#b8860b` · `#f3c34a` · `#e6c873`
- 상태색: 노랑 진영 `#f4d35e`/`#fdf3c9`, 갈색 진영 `#c1812f`/`#efe0d0`, 성공 `#16a34a`, 경고 `#ef4444`
- 폰트: system-ui (별도 웹폰트 없음)

## 3. 패널 구조(현재)
위에서 아래로: 제목(🐝 Be the Bee) → 턴 상태 박스 → 자원/점수 텍스트 → 설정 요약 한 줄 →
아코디언 섹션 5개. 각 섹션은 헤더(아이콘+제목+펼침 캐럿) + 본문(컨트롤 그리드 2열).

섹션과 그 안의 컨트롤:
- **게임**: 모드 드롭다운, 난이도 드롭다운, 여왕벌 모드(토글), 무한 모드(토글), 무르기, 복기,
  새 게임, 공유하기, 저장, 보관함
- **화면·설정**: 테마/벌 스타일(순환), 3D 보드(토글), 행동 버튼 위/아래(토글), 훈수(토글), 카메라 리셋
- **AI 설정**: AI 성향 드롭다운(+설명). 관전 모드면 색깔별 난이도·성향·관전 속도 슬라이더
- **사운드**: 재생/정지, BGM 곡 선택, BGM/효과음 음량 슬라이더 + 음소거
- **도움말**: 튜토리얼 다시 보기 + 규칙 안내 4줄

## 4. 이미 적용된 것(코드에서 처리 완료, 중복 작업 불필요)
- 첫 접속 시 5개 섹션 **전부 펼침**.
- 스크롤바를 **항상 표시 + 꿀빛 테마 + 폭 고정**(섹션 펼쳐도 레이아웃 안 흔들림).
- 아코디언 헤더: 꿀빛 그라데이션 + 미세 그림자 + 둥근 모서리.
- 섹션 헤더 5종 **자체 라인 아이콘**(게임=육각보드, 화면=눈, AI=로봇, 사운드=스피커, 도움말=물음표).
  `src/ui/icons.ts` 의 `ICON` 맵에 인라인 SVG 로 들어 있음(첫 세트, 교체 환영).

## 5. 해결하고 싶은 것 (Claude Design 에 부탁할 핵심)
지금 남은 문제: ① 버튼 안의 **이모지**(💾 📂 📤 🎨 🧊 🎵 🔊 📖 등)가 싸 보이고 AI 느낌. ②
설정 컨트롤이 **전부 흰 버튼**이라 "디자인된" 느낌이 없음.

### (A) 버튼/포인트 아이콘 세트
아래 이모지를 같은 라인 스타일의 자체 아이콘으로 교체. **규격 통일**이 핵심:
viewBox 24x24, `fill=none`, `stroke=currentColor`, stroke-width 1.8, 라운드 캡/조인,
색은 CSS `color` 로 지정(골드 `#c2982f`). 섹션 아이콘 5종과 한 세트로 보이게.

| 키(name)   | 현재 이모지 | 쓰임 |
|-----------|-----------|------|
| share     | 📤 | 기보 공유하기 |
| save      | 💾 | 현재 판 저장 |
| saves     | 📂 | 저장 보관함 |
| theme     | 🎨 | 색 테마 순환 |
| bee       | 🐝 | 3D 벌 스타일(제목에도 사용) |
| cube3d    | 🧊 | 3D 보드 토글 |
| music     | 🎵 | BGM 재생/정지 |
| soundOn   | 🔊 | 음소거 해제 상태 |
| soundOff  | 🔇 | 음소거 상태 |
| tutorial  | 📖 | 튜토리얼 다시 보기 |
| trophy    | 🏆 | 도움말: 승리 조건 |
| honey     | 🍯 | 도움말: 타일 놓기 |
| mouse     | 🖱️ | 도움말: 마우스 조작 |
| keyboard  | ⌨️ | 도움말: 키보드 조작 |

(원하면 섹션 5종 아이콘도 다시 그려도 됨: game/view/ai/sound/help.)

### (B) 컨트롤 스타일 (버튼 티 빼기) — 추천 방향
- **토글**(여왕벌·무한·3D·훈수·행동 버튼 위치): on/off 가 보이는 **스위치/필(pill)** 형태.
  켜짐일 때 꿀빛 채움 + 체크, 꺼짐일 때 옅은 테두리. 지금은 그냥 active 클래스(노랑 배경)뿐.
- **액션**(새 게임·공유·저장·보관함·복기·무르기·카메라 리셋): 아이콘 + 라벨의 **카드형 버튼**.
  통일된 둥근 모서리·옅은 그림자·hover 상승감.
- **드롭다운**(모드·난이도·성향): 지금의 ▾ 메뉴를 **세그먼트/셀렉트**처럼 정돈.
- **그룹 구분**: "설정(토글)"과 "행동(버튼)"을 시각적으로 구분(구분선 또는 묶음 배경).

## 6. 기술 제약 (반드시 지켜줘)
- **인라인 SVG only.** 외부 파일/폰트/아이콘 라이브러리 금지(이 앱은 에셋 0 정책).
- 결과는 **SVG path 문자열**로 줘서 `src/ui/icons.ts` 의 `ICON` 맵에 `name: svg('<path .../>')`
  형식으로 붙일 수 있게. (현재 헬퍼가 24x24·stroke 래퍼를 씌움 — path 안쪽만 주면 됨.)
- 장식 아이콘은 `aria-hidden`. 색은 하드코딩 말고 `currentColor`.
- 컨트롤 스타일은 **순수 CSS**(`src/style.css` 에 들어감). 새 의존성·JS 프레임워크 금지.
- 엔진(`src/engine`)은 절대 건드리지 않음. UI 만.

## 7. 받아서 통합하는 방법
1. 아이콘: 각 name 의 path 를 `icons.ts ICON` 에 추가 → 버튼 마크업의 이모지를 `${ICON.save}` 등으로 교체.
2. 컨트롤 CSS: `style.css` 의 `.settings-grid button` / 토글 / `.menu-wrap` 규칙을 제안 CSS 로 교체.
3. 통합 후 `npm run typecheck` + `npm run build` + `node scripts/verify-analysis.mjs` 로 회귀 확인.

## 8. 내 추천 한 줄
호박/꿀빛 톤 위에 **얇은 라인 아이콘(골드) + 둥근 카드 컨트롤 + 토글은 필 스위치**.
육각형(벌집) 모티프를 아이콘에 은은하게 반복하면 "한 세트"이자 게임 정체성이 살아난다.
