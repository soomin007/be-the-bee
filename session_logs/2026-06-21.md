# 2026-06-21 세션 로그

## 요약
Be the Bee 프로젝트 0단계 셋업. 맨바닥 Windows 환경(Node 없음, gh 없음, git만 존재)에서
Node.js·GitHub CLI 설치부터 Vite+TS(strict)+Vitest 스캐폴딩, GitHub 비공개 레포 생성·푸시까지
완료. 게임 로직은 아직 미구현 — 다음 단계는 엔진 모듈 구조 확정.

## 주요 변경
- 환경 설치: Node.js v24.17.0 + npm 11.13 (winget `OpenJS.NodeJS.LTS`), GitHub CLI 2.95.0 (winget `GitHub.cli`)
- `package.json` — scripts(dev/build/preview/test/test:watch/typecheck/check:engine), devDeps: vite 8 / vitest 4 / typescript 6 / @types/node 26
- `tsconfig.json` — strict + noUncheckedIndexedAccess 등 (DOM lib 포함, src/ui·tests용)
- `tsconfig.engine.json` — DOM/Node 타입 제거. `check:engine`으로 엔진 순수성 강제
- `vite.config.ts` — vitest 통합(test.environment='node')
- `src/engine/index.ts`, `src/ui/index.ts` — 계층 자리표시자(배럴)
- `src/main.ts`, `index.html`, `src/style.css`, `src/vite-env.d.ts` — UI 진입점/스캐폴드
- `tests/setup.test.ts` — 스모크 테스트 1개
- `.gitignore`, `.gitattributes`(LF 통일), `README.md`
- `rules.md` → `design/rules.md` 이동 (CLAUDE.md 규약 정렬)
- git init(main) + 첫 커밋 `7048f1f` → GitHub `soomin007/be-the-bee`(PRIVATE) 푸시

## 결정 사항
- **스캐폴딩을 손으로 작성**: 폴더에 PDF/CLAUDE.md/design이 이미 있어 대화형 `npm create vite`(폴더 비우기 프롬프트)가 위험 → 설정 파일 직접 작성으로 통제권 확보, 의존성 버전은 `npm install`이 최신으로 채우게 함.
- **엔진 순수성 강제 장치**: CLAUDE.md "engine은 DOM 금지"를 컴파일 단계에서 보장하려고 `tsconfig.engine.json`(lib에서 DOM 제외) + `check:engine` 스크립트 도입.
- **GitHub 인증**: 토큰 복사 대신 브라우저 device flow(`gh auth login --web`) — 초보자에게 가장 안전/간단. 비공개 레포로 시작(나중에 공개 전환 가능).
- **줄바꿈**: 크로스플랫폼/향후 Capacitor 대비 `.gitattributes`로 LF 통일.
- PDF(10MB)는 .gitignore하지 않고 저장소에 포함 — 게임 규칙의 최종 권위라 함께 버전 관리.

## 세션 2 — 엔진 + 핫시트 UI 구현

### 요약
규칙 6항목 확정 후 곧바로 Phase 1 엔진과 Phase 2 핫시트 UI를 완성. **브라우저에서 둘이
번갈아 한 판을 끝까지 둘 수 있는** 상태가 됨. 사용자 요청으로 Eyes on You식 문서/운영
구조도 셋업. 테스트 38개 통과.

### 주요 변경
- 엔진(`src/engine/`): `hex`(큐브좌표) · `types` · `state`(초기상태/접근자) ·
  `lines`(findLines, 한 스캔 두 용도) · `hive`(탐지/점수/잠금) · `victory`(말5목) ·
  `moves`(검증·적용·턴규칙·종료) · `index`(배럴). 커밋 `fe11411`.
- 문서/운영: `docs/INDEX.md`, `docs/ROADMAP.md`, `docs/design/backlog.md`,
  `docs/design/known_issues.md`, `CLAUDE.md` 운영 규칙 추가. 커밋 `7eb30b0`.
- UI(`src/ui/`): `layout.ts`(hex→픽셀) · `game-ui.ts`(렌더+입력+상태머신) ·
  `main.ts` 마운트 · `tests/ui.test.ts`(happy-dom). 커밋 `092be30`.
- `design/rules.md` v0.3 — §9 진행 세부(⚠️ 잠정 기본값) 추가.

### 결정 사항
- **엔진을 원자적 턴 Move로 모델링**: `twoTiles`/`tileAndPiece`/`pieceOnly` 한 번의
  applyMove로 처리. UI가 멀티클릭으로 Move를 조립한 뒤 커밋 → 엔진은 단순/순수 유지.
- **보드 = `Record<string,Cell>`**: Map 대신 직렬화 가능한 객체. CLAUDE.md에도 반영.
- **UI 클릭 판정**: pixel→hex 역변환 대신 각 SVG 헥스에 좌표 클로저를 실어 처리.
- **엔드게임 진행 세부**: 종이 설명서에 없어 `rules.md §9`에 잠정 기본값으로 명시(⚠️).
- **자주 끊어 커밋**: 엔진/문서/UI를 각각 별도 커밋으로 push (운영 규칙).
