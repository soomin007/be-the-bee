- PDF(10MB)는 .gitignore하지 않고 저장소에 포함 — 게임 규칙의 최종 권위라 함께 버전 관리.

## 세션 4 — vs AI + 관전 모드

### 요약
Phase 3 AI 구현. 이 게임은 헥스판 5목(Gomoku) 본질이라 분기계수가 커 **깊은 minimax 부적합** →
승리/차단 선견 + 1수 휴리스틱으로 빠른 AI 구성. vs AI + AI 관전 모드. self-play 테스트로
엔진 자동 검증. 전체 50개 테스트 통과.

### 주요 변경
- `src/engine/ai.ts`(신규): `createAi`/`Ai`, 승리→차단→Gomoku식 평가(findLines 재사용),
  시드 PRNG, 난이도 Cfg seam. `index` 배럴 추가. 커밋 `4167d7e`.
- `tests/ai.test.ts`(신규): 즉시승리·차단 3종·이중위협·allowedMoveTypes·결정성·self-play.
- `src/ui/game-ui.ts`: 모드(hotseat/vsAi/watch) 순환, setTimeout 스케줄러+재진입 가드,
  입력 잠금, 생각중 표시, 타이머 위생. UI 통합 테스트(fake timers). 커밋 `92d549b`.

### 결정 사항
- **깊은 minimax 대신 휴리스틱**: 분기계수가 체스보다 큼. 난이도는 "깊이"가 아니라 빔 서치로 확장.
- **AI 차단의 핵심**: 5목 완성 칸을 내 말로 점유해야 막힘(타일만 깔면 상대가 그 위에 말 가능).
  완성 칸은 기존타일·프론티어(타일+말 한 수)·빈틈 모두 포함해 탐지.
- **이동생성 O(board)**: 말 놓을 칸 X 기준 분해 + 부차 타일 1회 계산(칸×칸 페어링 금지).
- **여왕벌 정책**: 즉시승리/막을 수 없는 잠금 차단에만 사용(평상시 후보 제외).
- **self-play 테스트**가 엔진 회귀를 자동 검증 — 수동 플레이 부담 해소.

### 미해결 / 다음 할 일
- backlog 다음 후보: 직전수 강조 / 위험수 힌트 / 승리 카운트다운 / 승리 이펙트 / GitHub Pages 배포.
- AI 난이도 easy/hard(빔 서치) — Cfg seam만 있고 미구현.
- `rules.md §9` 진행 세부 ⚠️ — 사용자 확인 대기.

## 세션 6 — AI 허리끊기 + 설정/훈수 + 시청각 이펙트

### 요약
"AI가 벌집 완성 전 상대 타일 선점(허리 끊기)을 이해 못 한다"는 피드백 → 평가에 선점 가치를
넣고 어려움을 깊이4로 강화(hard 6:0 medium). 설정을 RoomSettings로 중앙화(멀티 로비 대비),
힌트는 훈수 모드에서만. 효과음(Web Audio 합성)·등장 애니메이션·BGM 토글 추가. 55개 통과.

### 주요 변경
- `engine/ai.ts`: `contestBonus`(상대 발전 타일선 위 내 말 선점), hard 깊이4·폭10. (`09a30ee`)
- `ui/game-ui.ts`: `RoomSettings`(모드/난이도/힌트/사운드), 난이도 선택·훈수 토글,
  힌트 게이팅, 직전 수 pop 애니메이션, 효과음/BGM 토글·트리거. (`1c06554`, `23eb994`)
- `ui/sound.ts`: Web Audio 합성 효과음 + BGM(public/bgm.mp3) 플레이어.
- `docs/design/bgm_prompt.md`: Suno BGM 프롬프트 3종.

### 결정 사항
- **PDF 전략을 평가에 직접 반영**: TIP#1 허리 끊기 = 상대 발전 타일선(곧 벌집) 위 내 말 선점만
  보상. 자기 타일선 발전은 보상 안 함(TIP#3 위반 → 회귀 유발, known_issues 기록).
- **설정 = 방 설정**: 멀티플레이에서 로비가 정해 양쪽 공통 적용되도록 한 객체에 모음(직렬화 가능).
  지금은 네트워킹 안 만들고 구조만 로비-친화적으로.
- **힌트는 훈수 모드 게이팅**: 기본 끔. 직전 수 강조는 피드백이라 항상.
- **효과음은 합성**: 오디오 파일 의존 없이 Web Audio로. BGM만 사용자 제공(Suno).
