## 결정 사항
- **되돌리기는 요청자만 수행 + 스냅샷 push**, 동의자는 구독으로 자동 동기화. 동의자도 로컬에서
  doUndo 하는 안(Option A)은 이중 되돌리기·스냅샷 불일치 위험 → 폐기. 신호는 모달 제어용으로만 쓰고
  실제 상태 변경은 단일 지점(요청자)에서 일으켜 기존 스냅샷 동기화 경로를 재사용한다.
- **온라인 무르기는 "내가 방금 둔 직후(상대 차례)"에만** 가능. 내 차례에는 막고 안내(notice).
  doUndo 가 hotseat 모드에서 한 수만 되돌리므로(AI 없음) 정확히 내 마지막 수가 무러진다.
- **undoUsed 는 진영별·로컬 추적으로 충분**(각 머신은 자기 진영 버튼만 게이팅, 요청자는 늘 자기 수를
  무름) → 네트워크 동기화 불필요.
- 요청 취소(undoCancel) 신호로 대기 모달을 비-막다른 길로. 요청자/동의자 신호 교차(취소 vs 동의)
  레이스는 `!online.undoReq`/`infoModal==='undoAsk'` 가드로 desync 없이 흡수(드문 케이스, 상태 무손상).

## 세션 3 — 모바일 페이지 스크롤 제거

### 요약
사용자 보고: 모바일에서 화면이 실제 뷰포트보다 커져 페이지 스크롤이 생기고, 그 탓에 앱 온보딩
(fixed 기반)이 어긋났다. 루트 스크롤을 명시적으로 잠그고 설정 시트·보드만 스크롤을 허용했다.

### 주요 변경
- `src/style.css`: `html/body/#app` 에 `overflow:hidden` + `overscroll-behavior:none` + 높이 고정
  → 루트 스크롤 차단. 설정 시트(`.panel`)에 `overscroll-behavior:contain` + 관성 스크롤(내부 스크롤
  유지, 끝에서 루트로 전파 X). 온보딩 오버레이(`.coach-layer`)에 `touch-action:none`.

### 결정 사항
- 원인은 `dvh`/주소창/safe-area 동적 변화(Playwright 에뮬레이션 미재현) → 정적 수정 불가, **루트
  스크롤을 잠그는 것이 정답**. 레이아웃이 이미 `100dvh`+flex(보드 `flex:1;min-height:0`)라 잠가도
  클리핑 없음. known_issues 에 재발 방지 기록.

### 미해결 / 다음 할 일
- 실기기에서 최종 체감 확인(루트 스크롤 사라짐·온보딩 위치 정상) — 사용자 검증 대기.

### 세션 3 후속 — iOS HUD 드래그·주소창 끌림
사용자 후속 보고: 상단 HUD(차례 표시)를 누르고 드래그하면 여전히 화면이 움직이고 주소창까지
끌려 올라감. `overflow:hidden` 만으론 iOS 에서 부족 → ① `body { position:fixed; inset:0 }` 로 페이지
고정, ② `.board-wrap`·`.m-fab` 에 `touch-action:none`(보드 팬은 JS pointer 라 유지, 설정 시트는
board-wrap 밖이라 자체 스크롤 유지 — 공통 조상에 주면 시트 스크롤도 막히므로 주의). known_issues
후속 기록. 검증: HUD 드래그 후에도 루트 scrollY 0, 보드 pan·시트 스크롤 정상.

### 세션 3 후속 2 — 화면 비율 복구 + 첫 턴 행동 버튼
사용자 보고: (S22+ 2340×1080) 끌림은 사라졌으나 화면 비율이 깨짐. 또 첫 턴엔 행동 버튼이 없어
온보딩 "수 두기"가 가리킬 게 없음.
- **비율**: `body{position:fixed}` 가 `#app` 의 100dvh 와 어긋난 게 원인 → body 고정 되돌리고
  `#app` 100dvh 를 단일 기준으로. 끌림은 `touch-action:none`(.board-wrap/.m-fab)이 이미 막음.
  검증: .game 이 뷰포트(384×854) 정확히 채움, HUD 드래그 후 scrollY 0, 보드 pan 정상.
- **첫 턴 버튼(사용자 선택 b)**: 가짜 튜토리얼 화면 대신 실제 UI 개선 — `startTurn` 이 타일 둘 수
  있는 턴이면 항상 chooseAction 표시(말만 두는 턴만 예외). 불가한 ①은 비활성+이유 title.
  onPanelAction 가드. tests/ui.test.ts 4개 + verify-click.mjs 새 흐름으로 갱신. 전부 PASS.

### 결정 사항(후속)
- 모바일 풀스크린 잠금은 **`position:fixed` 대신 `touch-action:none`(비스크롤 영역) + overflow/

- 첫 턴 행동 버튼은 **실제 게임 UX 개선으로 채택**(온보딩 전용 가짜 화면 회피) — 모든 턴이 행동
  선택으로 시작해 일관적이고, ① 비활성+이유로 규칙도 가르침.
