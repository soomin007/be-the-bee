## 결정 사항
- **온라인 중 '새 게임'은 경고 후 진행**: `leaveOnlineForNew`가 경고 없이 방을 떠나던 흐름을
  `newOnlineWarn` 게이트로 막음. "계속"은 마법사를 열고, 실제 이탈은 로컬/AI/관전 선택 시 일어남
  (재대국은 마법사 안에서 그대로 가능).
- **모바일 안내 중복은 추측성 코드 미작성**: 실제 Supabase 2-클라(모바일 게스트) E2E + 재연결·
  재접속 스트레스로도 모달은 항상 1개 → 단일 인스턴스 코드는 견고. 유력 원인은 "같은 브라우저에
  이미 열린 상태에서 링크를 또 열어 탭/인스턴스가 둘"(clientId 공유). 사용자도 재현 실패 → 기록만.
- **홍보물은 게임 자산 재사용으로 정체성 통일**: 포스터·캐러셀 모두 piece-art SVG·꿀 팔레트·
  honeycomb 보드를 그대로 써서 "프레임 캡처 같은" 진본 느낌. 외부 이미지 0(SVG/CSS + 구글폰트).
- **인스타는 4:5 메인**(피드 점유↑), 1:1 보조. 캐러셀 본문은 `word-break:keep-all` + 문장/구
  단위 `<br>`로 한글 단어 중간 잘림 방지(온보딩 때와 같은 규칙).
- 산출물 PNG는 `public/`에 두어 배포 URL 로도 공유 가능(shot-og 선례). 생성기로 재현 가능.
