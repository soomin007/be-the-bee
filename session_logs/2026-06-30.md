## 꽃 테마 추가(분홍·초록) — backlog #5

### 요약
색 테마(`src/ui/themes.ts`)에 꽃 계열 2종을 추가했다. 분홍(벚꽃·장미), 초록(민트·잎).
기존 `cobalt`(남색)처럼 진영 색·이름까지 테마에 맞춰 바꾸는 방식. 테마 선택 UI 는
`cycleTheme` 버튼이 `COLOR_THEMES` 배열을 순환하므로 배열 추가만으로 자동 반영(별도 UI 무).

### 주요 변경
- `src/ui/themes.ts`: `COLOR_THEMES` 에 두 테마 추가(`cobalt` 뒤).
  - `blossom`("벚꽃·장미", 분홍): yellow 슬롯=밝은 벚꽃, brown 슬롯=진한 장미. players '벚꽃'/'장미'.
  - `meadow`("민트·잎", 초록): yellow 슬롯=밝은 민트, brown 슬롯=진한 잎초록. players '민트'/'잎'.
  - 각 테마 tile(light/mid/dark/stroke)·piece(body/stripe)·hiveFill/Stroke·hiveGlow 정의.
- `docs/design/backlog.md`: #5 항목 제거(완료).

### 결정 사항
- **같은 계열 두 톤 + 명도 차로 진영 구분**: 분홍/초록 모두 한 계열 안에서 밝은 톤 vs 진한 톤으로
  두 진영을 갈랐다. 색약 친화는 이미 `contrast`/`cobalt` 가 담당하므로 꽃 테마는 심미 우선 OK.
  팔레트 미리보기(인라인 SVG 스크린샷)로 타일·말·벌집 모두 두 진영이 또렷이 구분됨을 눈으로 확인.
- **원판은 고동색 공통 유지**: known_issues(2026-06-23) "진영 구분=벌 색, 원판=고동 고정" 따라 disc 는
  안 건드리고 piece.body 색만 진영별로 다르게. 꽃 테마도 같은 규칙.
- **3D 모드 미적용**: 현 사양(3D 는 테마 미적용) 그대로 — 2D SVG 색만 추가.
