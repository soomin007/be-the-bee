## 꽃 테마 추가 — backlog #5

### 요약
색 테마(`src/ui/themes.ts`)에 꽃 테마 1종 `bloom`("벚꽃·민트")을 추가했다. 한 진영=분홍 벚꽃,
다른 진영=초록 민트. 두 색의 색상(hue) 차가 커서 진영 구분이 가장 쉽다. 테마 선택 UI 는
`cycleTheme` 버튼이 `COLOR_THEMES` 배열을 순환하므로 배열 추가만으로 자동 반영(별도 UI 무).

### 주요 변경
- `src/ui/themes.ts`: `COLOR_THEMES` 에 `bloom`("벚꽃·민트") 추가(`cobalt` 뒤).
  - yellow 슬롯=분홍 벚꽃, brown 슬롯=초록 민트. players '벚꽃'/'민트'.
  - tile(light/mid/dark/stroke)·piece(body/stripe)·hiveFill/Stroke·hiveGlow(분홍빛) 정의.
- `docs/design/backlog.md`: #5 항목 제거(완료).

### 결정 사항
- **처음엔 2종으로 잘못 만듦 → 1종으로 합침**: 백로그가 "분홍·초록 2종"이라 적혀 있어 `blossom`(분홍
  벚꽃 vs 진한 장미)·`meadow`(밝은 민트 vs 진한 잎) **두 테마**로 만들었는데, **한 테마 안의 두 진영이
  같은 계열**(분홍끼리/초록끼리)이라 헷갈린다는 사용자 피드백. → 한 테마 안에서 **분홍 진영 vs 민트
  진영**(색상 대비)으로 합쳐 `bloom` 하나로 교체. 같은 계열 두 톤은 명도 차를 줘도 게임 중 구분이 약함.
- **원판은 고동색 공통 유지**: known_issues(2026-06-23) "진영 구분=벌 색, 원판=고동 고정" 따라 disc 는
  안 건드리고 piece.body 색만 진영별로 다르게.
- **3D 모드 미적용**: 현 사양(3D 는 테마 미적용) 그대로 — 2D SVG 색만 추가.

### 검증
- `npm run typecheck` OK · `npm test` 104 통과 · `npm run build` 성공.
- 팔레트 스크린샷(scratchpad, 인라인 SVG)으로 분홍 진영 vs 민트 진영이 타일·말·벌집 모두 또렷이
  구분됨을 확인. dev 서버 미사용.

## 복기 UI 리모컨화 + 미니플레이어 펼침 버그 — backlog #4

### 요약
복기(리뷰) 모드 UI 를 "보드 위 하단 리모컨"으로 통일했다. 복기 진입 시 설정 패널/시트를 자동으로
닫아 보드를 보며 조작하게 하고(사용자 요청 — 특히 모바일에서 설정창 닫아야 보드 보이던 문제),
데스크탑·모바일 공통 리모컨을 만들었다. 더불어 음악 미니플레이어 펼침 시 화면 밖으로 나가던 버그 수정.

### 주요 변경
- `src/ui/game-ui.ts`:
  - `handleReplay('replayEnter')`: 복기 진입 시 데스크탑 `panelCollapsed=true`(진입 전 상태 저장→종료 시
    복원), 모바일 `mobileShell.setSettings(false)`. `replayToggleAnalysis`(분석 펼침 토글) 케이스 추가.
  - `renderReplayRemote()` 신설: 진행(N/M) + 처음/이전/재생·멈춤/다음/끝 + 진행 슬라이더 + 이 판
    분석(접이식) + 종료. `renderActionBar` 가 복기 중이면 데스크탑·모바일 공통으로 이걸 렌더.
  - 데스크탑 패널 교체식 `renderReplayPanel` 제거(분석 HTML `replayAnalysisHtml` 은 리모컨이 재사용).
- `src/ui/draggable.ts`: `ResizeObserver` 추가 — 미니플레이어가 알약→카드로 커질 때 새 크기로 다시
  화면 안에 가둔다(우하단 끝에 둬도 펼칠 때 안 삐져나감).
- `src/style.css`: `.replay-remote` 라이트/다크 스타일 + ab-top 이어도 복기 리모컨은 항상 하단(order).
- `src/ui/mobile.css`: 복기 리모컨 하단 중앙 풀폭 + 터치 버튼 크기 + 좁은 폭에서 진행표시 숨김(짤림 방지).
- `tests/ui.test.ts`: 복기 단언을 `.replay-remote` 기준으로(패널 교체 제거 반영).

### 결정 사항
- **복기 = 하단 리모컨 통일**: 데스크탑은 패널 교체(못생김), 모바일은 시트 안 닫혀 보드 안 보임 →
  둘 다 보드 위 하단 리모컨으로. 행동바 위/아래 설정과 무관하게 복기 리모컨은 항상 하단(사용자 요청).
- **미니플레이어**: 위치를 left/top 으로 저장하는데 알약 크기 기준 clamp 라 카드로 펼치면 초과 →
  ResizeObserver 로 크기 변화 시 재clamp(가장 견고, game-ui 호출 불필요).

### 검증
- typecheck·build·104 테스트 통과.
- 실브라우저 자동 검증(Playwright): 데스크탑 라이트/다크 — 복기 진입 시 패널 닫힘(collapsed=true) +
  하단 리모컨 + 분석 펼침, 에러 0. 모바일 — 톱니→시트→복기 시 **시트 닫힘(sheetOpen2=false) +
  리모컨 표시(remote=1)**, 버튼 한 줄(짤림 없음). 즉 코드는 데스크탑·모바일 모두 정상.
- 검증 함정(기록): 새 게임 마법사 모달 버튼은 dispatchEvent/force click 모두 안 먹어(실제 마우스만)
  자동 검증이 마법사를 못 닫음 → 데스크탑은 보드 dispatchEvent 클릭으로 우회, 모바일은 7수 후 reload
  (자동저장 복원)로 마법사 스킵해 검증. 보드 폴리곤 클릭도 dragMoved 때문에 좌표 클릭 대신 dispatchEvent 필요.
