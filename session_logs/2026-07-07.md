## 결정 사항
- **프로브를 typecheck 에서도 제외**(tsconfig include 밖): 연구 코드가 배포를 깨뜨릴 표면 자체를
  제거. 대신 프로브 수정 후엔 `npm run probe` 로 직접 실행 확인(probes/README 에 명시).
- **export-hook/ PNG 는 커밋하지 않고 gitignore**(사용자가 위임): 5MB 바이너리 홍보 이미지는
  코드 저장소 밖 보관이 맞다고 판단. 파일은 로컬에 그대로 있음.
- **verify 복구는 스크립트 패치가 아니라 공용 헬퍼(boot.mjs) 도입으로**: 다음 UI 개편 때 고칠
  곳을 한 곳으로 모음. 새 스크립트는 `prepPage` 부터 시작.
- **verify-watch-control 의 "모드 선택만으론 자동 시작 안 함" 단언 폐기**: 그 UI(설정 메뉴 모드
  변경)가 사라지고 마법사 "시작"은 의도적으로 바로 진행이라, 현 사양(⏸/▶ 동작)으로 재작성.
- **game-ui 분해는 결합도 낮은 순서로 세션당 1모듈**: 1단계 settings(클로저 의존 0)로 패턴 확립.
  다음 후보와 요령은 backlog #3.
