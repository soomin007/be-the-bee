## 결정 사항
- **`hide()` 가 표시 예약(cancelPendingShow)까지 겸한다**: 원래 코드는 clearAiTimer 에서
  loadingTimer 해제와 hideAiThinking 을 따로 했지만, "숨김 = 예약도 취소"가 항상 안전한
  상위 집합이라 API 를 하나로 합침(호출부 단순화).
- **오버레이 DOM 은 모듈이 생성**(셸 템플릿에서 제거): board3d-host 처럼 JS 로 append.
  CSS 는 클래스 셀렉터만 써서(absolute 오버레이) DOM 생성 위치가 바뀌어도 무관.
  기존 `.ai-thinking-*` 클래스명 유지 → `verify-ai-loading.mjs` 단언 그대로 통과.
- **이전 줄 수 기록 부정확 발견**: backlog·세션 로그의 "3단계 후 3,577줄"은 실측과 다름
  (HEAD 기준 wc -l 3,724줄). 이번부터 wc -l 실측만 기록. 07-07 로그의 "3730 오기" 건과
  같은 계열 실수 — 줄 수는 적기 전에 wc -l 로 잰다.
