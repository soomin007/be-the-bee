정리하는 GitHub Actions 크론을 추가해 유지보수와 활동 유지를 동시에 해결하고, 수동 실행으로 검증했다.

## 결정 사항
- **단순 핑이 아니라 "낡은 방 정리"를 크론으로 돌린다.** 어차피 필요한 유지보수이고, 그 요청 자체가
  활동으로 잡혀 일석이조. 정리 기준(24h, `updated_at`)은 앱의 `cleanupOldRooms` 와 동일하게 맞춰
  기준이 두 갈래로 갈라지지 않게 했다(게임 UI 도 사용자에게 "24시간" 이라 안내 중).
- **Pro 업그레이드($25/월)는 보류.** 실제로 온라인 대전을 쓰는 사람이 생긴 뒤 판단할 일.
- 주기는 3일 — GitHub schedule 은 지연될 수 있어 7일 한계에 4일 여유를 뒀다.
